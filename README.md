Este es un programa sencillo para completar el Challenge de AluraLATAM sobre el Conversor de Monedas.

Se utilizó Java 21 para el proyecto.

Los pasos a seguir son sencillos, el usuario tendrá la opción de elegir una moneda dentro de las opciones disponibles y podrá convertirla a otra moneda.
Se podrá utilizar una cantidad personalizable y al obtener el resultado también se le entregará al usuario la tasa de cambio como referencia.
Finalmente el usuario puede elegir reiniciar para probar más cambios de moneda o salir en cualquier parte del proceso para terminar la solicitud.

Los datos se extraen desde la página exchangerate-api.com por lo que dependiendo de su API irá cambiando el valor de las tasas de cambio.
